## 真实协议回环

启动完整 OB HTTP 进程，使用独立临时 vault、关闭外部向量服务、随机测试 Token 和虚构原话：

1. 通过真实 HTTP MCP initialize／tools/call 写入 GPT 来源原话。
2. 通过原版 hold 写入一条虚构长期记忆。
3. Node Cyberboss 服务通过真实 HTTP 归档微信消息并取得上下文；同时拿到 GPT 原话和上述长期记忆。
4. 通过真实 HTTP MCP 查询微信原话，按编号读回全文。
5. 终止并重新启动完整 OB 进程，三条共享原话仍在。

未使用用户真实微信登录、真实聊天、私人记忆或模型 API Key。长期记忆测试使用原版无 Key 退化路径，不能代表真实向量服务质量或真实模型回复质量。
