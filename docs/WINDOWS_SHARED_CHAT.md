# Windows 本机共享记忆 B

本版继续使用 Ombre Brain，不使用 Serein。先在 Windows 电脑上运行，暂不新增服务器月费。模型 API 如需使用，仍按供应商计费；安装时不购买服务或申请新 Key。

## 第一次只需打开安装包

1. 把 ZIP 完整解压到准备长期保留的文件夹，不要在 ZIP 里直接运行。
2. 双击最外层 `Install.cmd`。有 Python 3.12 会直接使用；没有则尝试通过 Windows 自带 winget 为当前用户安装。winget 不可用时会明确停下，不会提示已经装好。
3. 菜单选 **1 安装依赖**，等待完成；再选 **2 启动记忆库**。初次下载可能需要几分钟。保持新打开的记忆库窗口运行。
4. 菜单选 **7 打开记忆管理页面**。密码只显示在你电脑上，不需要发到聊天里。

暂时不填模型 Key 也能归档、查询聊天原话。压缩、向量化、长期记忆质量仍需在管理页面配置供应商后另行验收。不要把管理页面配好的新 Key 发到聊天里。

数据和密钥默认在 `%LOCALAPPDATA%\OmbreBrainShared`，与解压出来的源码分开。重复打开不会重新生成密钥或覆盖已有配置。记忆库只监听 `127.0.0.1:18001`，不会开放到局域网或公网。

## 接入你现有的微信

先关闭正在运行的微信助手，避免旧进程继续使用旧代码。菜单 **3 接入现有微信** 会弹出三个选择框：

1. 选实际代码文件夹，里面能看到 `src/core/app.js`。不要只选 `.cyberboss-xlc` 的最外层；实际代码可能在它的 upgrade-staging 子目录。
2. 选当前伴侣的工作区，通常为 `.cyberboss-xlc/workspace`，以实际绑定为准。
3. 选你平时双击的微信启动 `.cmd` 或 `.bat` 文件。

安装器先在隔离副本做 `git apply --check`，只有增量补丁能应用才备份原文件并替换对应的修改结果。它保留原代码里无关的定制，不换成包内的整套微信程序，不复制账号、会话、人设或历史。重复接入能识别已经应用的补丁。

有冲突时原文件不变，生成 `wechat-code-backups/compatibility.json`，只含固定代码文件的哈希值，可以发来排查。它不含源代码、密钥和聊天内容。哈希只能定位版本；若定制代码产生冲突，后续仍需按实际改动合并，不能保证自动兼容所有二改。

成功后会备份并追加一个独立的 Codex MCP 配置，名称为 `ombre_brain_shared`。默认读取 `%USERPROFILE%\.codex/config.toml`；若安装助手自身有 `CODEX_HOME`，则读取该目录。已有同名不同配置时会停下，不重写。若你的原启动文件另外设置了 `CODEX_HOME`，需要让安装助手使用同一目录后再接入，否则微信的长期记忆写入工具可能不可见。

以后通过菜单 **4 用原来的启动文件打开微信**，它会向原启动流程传入共享记忆环境变量。原启动文件仍决定账号、模型、免打扰和其他定制行为。若直接使用原图标而未经过本助手，新增的环境变量不会自动存在。

微信发送 `/status` 检查 OB 是否启用、是否有待补传或被隔离的消息。接入不改变原来的工作区绑定；若运行的是另一个工作区，本版不会替它开启共享。

## ChatGPT 多窗口

电脑本机地址不能直接给云端 ChatGPT 使用。本助手提供 **5 连接 ChatGPT 私有隧道**，采用 OpenAI 官方 Secure MCP Tunnel：

- 需要你的 OpenAI Platform 账号有 Tunnels 入口、创建权限，且隧道关联当前 ChatGPT 工作区；运行密钥需要 Tunnels Read + Use。
- 第一次打开官方页面后创建或复用隧道，把 `tunnel_id` 粘到本机助手。运行密钥通过本机不回显输入，不写入配置文件、不作为命令参数、不发到聊天中；关闭隧道后下次需重新输入。
- 助手从官方最新发布页下载匹配 x64/ARM64 的客户端，核对 GitHub 提供的 SHA-256，再运行 quickstart 帮助、doctor 和前台 run。`/readyz` 通过只表示隧道准备好，不代表 ChatGPT 已接入。
- 在 ChatGPT 添加自定义 MCP，连接方式选 **Tunnel**，选择同一条隧道。此私有入口选 **No authentication**：访问由平台隧道权限控制，运行器用环境引用向本机 OB 注入独立 MCP Token；本机 OB 的鉴权没有关闭。
- 如果没有入口、无权限或当前 ChatGPT 工作区不能使用，停在这里，本机微信仍可使用。不要为了绕过限制把本机 OB 改成免鉴权公网服务。

每个要共享的 GPT 窗口都需要实际启用同一个 MCP；安装一次不会自动读取所有历史，也不会自动抓取每一句新聊天。第一版由 GPT 调用 `chat_append` 保存已明确提供的原话，用 `chat_search` 找到其他窗口与微信已经归档的消息，再用 `chat_read` 回读完整原文。长期记忆继续由原 OB 的 breath、hold、grow 等工具处理。

建议每个窗口提供固定且不同的 conversation_id；同一条原话重试沿用 message_id 和发生时间。不得把猜测、改写摘要或隐藏思考冒充聊天原话。

官方说明：https://developers.openai.com/api/docs/guides/secure-mcp-tunnels

## 每次使用与备份

- 双击 `Install.cmd` → **2 启动记忆库** → **4 启动微信**；需要 ChatGPT 时再选 **5**。
- 记忆库窗口、微信窗口、需要时的隧道窗口都要保持运行。关机、休眠或断网期间远程访问会失败；关闭安装助手菜单本身不会关闭已经启动的窗口。
- 停止 OB：在记忆库运行窗口按 Ctrl+C。停止隧道同理。脚本不会结束不明进程或修改电源设置。
- 停止 OB 后，菜单 **8** 备份整个本机数据目录，排除依赖与下载工具。备份含原话与凭据，放在自己信任的位置。微信自己的 outbox、账号、人设、工作区不在这份备份内，需另外保存。
- 微信源代码备份位于 `wechat-code-backups`；每次成功修改都会保留原文件与 `restore.json`。若回退代码，先停微信，按该清单恢复原文件，移走 `missing_before` 列出的新增源文件；不要删除真实记忆或微信 outbox。
- 包内 `reference/cyberboss` 是对应补丁的公开源码参考，不是要你换用的新微信安装目录。许可证随各自源码保留。
